# Ace 原生加载器 FDT 内存检查

新增 `ace/fdt.c/.h` 为 freestanding C 提供有界、零分配的 FDT 索引。
`ace/xnu_fdt.c/.h` 从成功解析且保持稳定的 FDT 重新建立内存排除策略，
供已有 CPU 检查和有界 materializer 使用。它们已用于
[原生 EL1 Image](ACE-XNU-NATIVE-ENTRY.zh-CN.md)，尚未在手机执行。

## 解析与内存契约

输入上限 2MiB、4,096 节点、16,384 属性、64 层深度、256 个 header
保留区。解析检查所有读取边界、块顺序、名称终止、同级节点/属性重名、
属性必须先于子节点、精确 FDT_END 和 header 保留区溢出/重叠。只接受
版本 17、最低兼容版本不高于 17。仅访问者拥有的工作区会被写入；
与输入相交的工作区会拒绝。只能使用返回成功后的索引。

真实 Ace DTB 的最低兼容版本为 2，部分填充字节非零。解析器遵循
[libfdt 对兼容版本与对齐的处理](https://github.com/dgibson/dtc/blob/main/libfdt/fdt.c)，
跳过有界填充而不解释其内容；结构和数值字段仍严格检查。
[DTB 格式规范](https://devicetree-specification.readthedocs.io/en/stable/flattened-format.html)
是 token、块布局和属性顺序的交叉核对来源。

工作区为 282,656 字节，必须由调用者放在目标 RAM 之外，不能分配到小
启动栈上。Cortex-A55 `-fstack-usage` 表明解析函数单帧为 304 字节，
策略函数单帧为 4,352 字节（移除绝对字符串指针数组后的结果）；这不是
整个启动调用链的栈上限保证。

策略要求 MT6895 根身份、2/2 地址/大小单元、一个完整内存银行包含整个
管理窗口、32MiB 对齐、40 位 PA 上限，以及调用者明确声明的 Linux
启动前阶段。header 保留区、实时 FDT 自身、initrd、固定 reserved-memory、
有界动态分配域、源载荷、加载器/栈/工作区等调用者排除区都会检查，任一
区间与整个 XNU 管理窗口相交便拒绝。未知无界动态保留区不会自动忽略。

只有名称、属性集合、大小和对齐均与已核对声明一致的两个 Linux
SSMR/SSHEAP CMA 池可以保持未实例化；修改声明或增加未知属性会拒绝。
输出内嵌保留区数组，`policy.reserved` 指向该数组；输出对象须保持原位
并存活到加载器返回。错误返回不改变输出。新策略比旧主机清单额外加入
源载荷区间，即使它已包含在加载器的大排除区内也仍明确记录。

阶段参数是调用者契约，函数不能证明固件阶段。FDT 声明也不能证明
TEE、固件或 DMA 已释放 RAM、其他 CPU 已静止或缓存一致性成立。当前
接口检查内存描述，不完整检查 GIC、timer、PSCI、CPU/ADT 属性一致性；
这些仍须接入原生加载流程。不得据此在运行中的 Android 上写物理内存。

独立的 [初始平台比较模块](ACE-XNU-PLATFORM-CHECK.zh-CN.md) 现已核对
CPU/GIC/timer/PSCI 描述及规范 Ace ADT，并在手机 EL0 进程验证。原生
入口、即时特权状态和固件内存归属仍需整合，不能以描述比较代替启动。

## 验证结果（2026-10-20）

新鲜真机 FDT SHA256 为
`68c811fbaae657372d740c25ff81f03c9763eab3e897b0a7104d624ec598560b`，
与已有候选来源一致。原生 C 对它生成的 53 个区间与主机 Python 生成器
的 52 个区间加明确源载荷区间相等。

8 项新回归包括重复/损坏/截断输入、源与工作区别名、动态保留区变化、
出错前不写输出、真实 FDT 对照、无运行库导入和 ELF 装载布局。
ASan+UBSan 执行 3,000 次变异/截断，输入保持不变，策略拒绝时输出未改。

真实手机执行同一 C 解析器与策略代码的普通 EL0 诊断退出 0，UID2000、
CPU0、1,830 节点、9,757 属性、53 排除区；Android 阶段调用明确拒绝。
这是实际手机上的进程内解析和数值重放，没有原生加载或 XNU 跳转。
程序哈希、首次失败及清理记录见
[诊断说明](../diagnostics/ace-fdt-policy/README.md)。

实际 Ace 内核载荷在主机串联 FDT 策略、CPU 检查夹具和真实 C materializer
成功：10 个段的字节、966,656 字节 BSS 清零、ADT、BootArgs 均已核对。
CPU 状态与原生阶段明确为夹具；目标为主机映射。没有把内核复制到手机。
证据保存在私有 `research/ace-native-fdt-20261020/`。

仍须完成原生入口整合、即时 CPU/FDT/ADT 一致性、固件内存归属和最早
XNU 日志，再提出可审查的具体真机启动镜像。MTK UFS、显示和触摸尚未
运行，iOS 目标保持未完成。
